# BLIP Visual Question Answering — Fine-Tuning Experiments

This repository contains exploratory notebooks and a recorded demonstration for fine-tuning a BLIP-based Visual Question Answering (VQA) model.

## Repository contents

- `vqa-blip-model-fine-tune First verson.ipynb` — first fine-tuning experiment.
- `vqa-blip-model-fine-tune Second Version LLM Tuned.ipynb` — follow-up notebook exploring an LLM-assisted version.
- `VQA BLIP MODEL Fine tuned.mp4` — recorded project demonstration.

## Related project

The more complete application and project documentation for the multilingual Bangladesh cultural-heritage VQA system are maintained in [Capstone-Project](https://github.com/imtridib/Capstone-Project). Review that repository for the application flow, training notes, and deployment instructions.

## Working with the notebooks

1. Open the notebook in Jupyter or upload it to a notebook environment such as Kaggle.
2. Review the imports and dataset/model paths in each notebook before running cells.
3. Configure the dataset and checkpoint paths for your environment.
4. Run cells in order, adjusting GPU/runtime settings as needed.

The original notebook files may depend on datasets, checkpoints, and environment paths that are not included here. Reproducibility may require restoring those assets and matching the libraries used in the notebooks.

## Scope

This repository is an experiment/history repository, not a standalone packaged application. Model performance should be reported only alongside the exact dataset, evaluation split, and metric calculation used for that experiment.
